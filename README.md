# SQL Server Projects

A collection of projects and scripts built using **Microsoft SQL Server (T-SQL)**.  
This repository includes practical queries, performance improvements, and real-world problem-solving examples.

## Features
- Advanced SQL queries (CTEs, Window Functions, Joins)
- Performance optimization examples
- Data analysis and database management scripts

## Language Used
- **SQL Server (T-SQL)**

## Project Structure
Each file includes:
- A short description
- The SQL script
- Notes or insights related to the solution

## Purpose
To document and share practical SQL Server solutions that can be reused or expanded in future projects.
